# Day 12 - Number Guessing Game
Author: Vindhya Hasini


## Description
This is a console-based Number Guessing Game built in Python. The computer randomly selects a number between 0 and 100, 
and the player must guess it within a limited number of attempts. The game provides hints after every incorrect guess
and supports multiple rounds without restarting the program

## Features

### Original Project (based on course content)
* Random number generation between 0 and 100
* Two difficulty levels:
  * Easy -- 10 guesses
  * Hard -- 5 guesses
* Hint system ("Too low" or "Too high")

* Option to replay the game
* Input validation for difficulty level and guesses
