# Day 02: Tip Calculator
Author: Vindhya Hasini

## Description
This program allows the user to enter the total bill amount, desired tip percentage and number of people sharing the bill.
The program then calculates and returns the amount each person has to pay.

## Concepts Learned
* input() prompt
* Data types (int, float, string)
* Type conversion
* Mathematical operations
* f-strings
* Rounding numbers using round()

## Sample Input
Bill Amount: 1800
<br>
Desired Tip Percentage: 10
<br>
Number of people: 5

## Sample Output
Total bill: $1980.0

Each person has to pay $396.0

## Key Takeaways
Learned how to work with numerical calculations, convert user input into appropriate data types, and format output for better readability.
