# Day 05 - Password Generator Project
Author: Vindhya Hasini

## Description
This program generates secure random passwords based on the number of letters, symbols and numbers specified by the user.

The repository contains two versions of the project:

1. Original Version (main.py)
    
    The solution developed while following Dr. Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp

2. Upgraded Version (password_generator_upgraded.py)

    An extended version built independently with additional features beyond the course requirements

## Concepts Learned
* Python lists
* the random module
* random.choice()
* random.shuffle()
* string manipulation and traversing
* functions
* dictionaries
* file handling -- text file
* input validation

## Features in the Original Version
* Generate a random password 
* Customize the number of letters, symbols and numbers
* Randomize the password character order for a stronger password

## Features in the Upgraded Version
* Generate multiple passwords using the same settings
* Password strength analysis
* Save passwords under account names
* Retrieve previously stored passwords by specifying the corresponding account name
* Display stored account information
* Persistent storage using text files
* Menu-driven interface

## Upcoming Features for the Upgraded Version
* Save your own password into the program memory
* Input Validation
* Update the password for a given account 

## Key Takeaways
* Learned how randomization can be used to generate secure passwords
* Practiced working with lists and strings
* Used functions to organize a larger program
* Learned how dictionaries can be used to manage account-password pairs
* Implemented file handling to store data permanently
* Improved problem-solving by extending a simple project 

## Note
The original version was completed as a part of Dr. Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp

The upgraded version was designed and implemented independently as an additional challenge to explore 
file handling, data persistence, and program design beyond the course requirements.

Passwords are stored as plain text for educational purposes and should not be used to store real passwords.
