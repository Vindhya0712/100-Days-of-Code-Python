# Day 11 - Blackjack Game
Author: Vindhya Hasini

## Description
This project is a console-based game implementation of the popular card game -- Blackjack, built in Python.

The game allows the user to play against the computer as the dealer, make strategic decisions by choosing whether to hit
or stand, and play multiple rounds without having to restart the program. The project includes Blackjack detection, score
comparison, input validation, and a cleaner user-experience through console clearing and formatted game output.

## Features in the Original Version (main.py)
* Random card dealing for the player and the dealer
* Blackjack Detection
* Ace conversion to prevent unnecessary busts
* Hit and Stand gameplay options
* Dealer decision-making logic
* Win, loss, draw and bust detection
* Play-again functionality
* Input Validation
* Console clearing between rounds
* Emoji-enhanced game feedback
