# Day 26 - NATO Alphabet
Author: Vindhya Hasini

## Description
This Python program converts a word entered by the user into its corresponding NATO Phonetic alphabet code words

For example:
Input: Vindhya
Output: ['Victor', 'India', 'November', 'Delta', 'Hotel', 'Yankee', 'Alfa']

## Files in this directory
| File Name                  | About                                                         | Status       |
|----------------------------|---------------------------------------------------------------|--------------|
| main.py                    | Contains the main code for the project                        | ✅ Completed |
| nato_phonetic_alphabet.csv | A csv file containing the alphabets and their NATO code words | ✅ Completed |


## Concepts Learned
