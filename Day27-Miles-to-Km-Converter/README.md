# Day 27 - Miles to Km Converter Widget
Author: Vindhya Hasini


## Description
A simple GUI-based unit converter built using Python and Tkinter. The widget allows the user to enter a distance in
miles and returns the distance converted to kilometers with the click of a button.

This project was my first experience in creating a GUI and working with the Tkinter module.

## Key Takeaways
This project helped me understand how Python can be used to build interactive GUI applications rather than just relying
on command-line applications

The first biggest lesson I learnt through this project was how **args and **kwargs work. They helped me understand why
Tkinter doesn't really show any parameters as hints while typing the code

The second-biggest lesson I learnt was working with the Tkinter module itself. I learnt how to create an interactive UI.
I learnt how Tkinter works with events instead of executing everything sequentially.
