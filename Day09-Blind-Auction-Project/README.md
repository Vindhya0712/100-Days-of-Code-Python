# Day 09 - Blind Auction Project
Author: Vindhya Hasini

## Description
This project is a simple Python-based blind auction system where multiple bidders can place secret bids and the program decides the final winner based on the highest bid.

## Concepts Learned
* Python dictionaries
* Nested 'for' and 'while' loops
* Functions
* Conditional statements
* Clearing the console using the os module
* User input validation
* String methods like .isdigit() and .lower()
* Iterating through dictionaries
* Finding maximum values in a collection
* Basic debugging techniques

## Key Takeaways
* Learnt breaking program into simple to-do's to manage complex ideas
* Input validation is important to avoid program crashes
* The first solution that comes to mind is not always the simplest or best one
* Debugging leads to deeper understanding of the language
* Dictionaries are extremely useful while expressing real-word data relationships
* Planning future improvements helps identify limitations of current design
* Clean and readable code becomes increasingly important as size and complexity of project increases
* Learned the importance of shipping a finished project before chasing upgrades
