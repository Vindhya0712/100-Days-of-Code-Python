# Day 04 - Rock Paper Scissors Game
Author: Vindhya

## Description
This is an interactive version of the classic Rock-Paper-Scissors Game. 
The program allows the user to play Rock-Paper-Scissors against the computer by entering valid inputs.

## Concepts Learned
* Lists and list indexing
* The random module
* Generating a random integer using the random.randint()
* Nested conditionals
* Input validation
* Handling invalid user inputs

## Key Takeaways
* Not all cases can be solved using simple comparisons, some cases need special handling
* Order of conditional statements can affect the program behaviour and result
* User input should always be validated before being used to avoid crashing the program
* Testing edge cases helps identify logical errors
* Used Python lists to store and display ASCII art effectively
* The random module can be used to generate unpredictable computer choices.
